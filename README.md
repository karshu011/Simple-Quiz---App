# 📝 Simple Quiz App

A simple and interactive Quiz application developed using HTML, CSS, and JavaScript. This application allows users to answer multiple-choice questions and check their scores.

## 🚀 Features

- ❓ Display quiz questions
- 🔘 Multiple-choice answers
- ✅ Select the correct answer
- 📊 Calculate total score
- 🏆 Display final results
- 🔄 Restart the quiz
- 🎨 Simple and user-friendly interface
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.
3. Open `index.html` in your browser.
4. Read the questions and select your answers.
5. Submit your answers to view your score.
